# 🚦 Stage-Gate System (Robert G. Cooper)

Formulated by Robert G. Cooper, the **Stage-Gate System** is a formal risk management and capital allocation framework that divides the innovation lifecycle into distinct **Stages** separated by evaluation **Gates**.

---

## 🏗️ Structure of Stages & Gates

```
┌──────────┐   ┌─────────┐   ┌─────────┐   ┌─────────┐   ┌─────────┐   ┌─────────┐   ┌──────────┐
│  IDEA    ├──►│ GATE 1  ├──►│ STAGE 1 ├──►│ GATE 2  ├──►│ STAGE 2 ├──►│ GATE 3  ├──►│ LAUNCH   │
│ GENERATION│  │ Scoping │   │ Technical│  │ Business│   │ Pilot / │   │ Full    │   │ Market   │
│          │   │         │   │ Check   │   │ Case    │   │ Dev     │   │ Launch  │   │ Scaling  │
└──────────┘   └─────────┘   └─────────┘   └─────────┘   └─────────┘   └─────────┘   └──────────┘
```

---

## 🔑 Key Rules of Stage-Gate Governance

1. **Incremental Capital Deployment**: Capital commitments increase exponentially at each stage. Early stages (scoping/probing) receive micro-funding, while major capital is reserved for post-Gate 3 scaling.
2. **Hard Gate Criteria**: A project cannot proceed to the next stage unless it satisfies all explicit quality, technical, financial, and regulatory benchmarks established for that Gate.
3. **Go / Kill / Hold / Recycle Decisions**: Every Gate review yields one of four definitive outcomes:
   - **Go**: Move to the next stage with approved budget.
   - **Kill**: Terminate the project immediately.
   - **Hold**: Pause pending external changes.
   - **Recycle**: Return to current stage to resolve missing requirements.

## 💡 Application in Project PRODIGY

The **Srujana 4-Stage Pathway** in PRODIGY is built on Stage-Gate principles:
- **Gate 1 (Stage -1 $\rightarrow$ 1)**: Micro-challenge completion & PVI score check.
- **Gate 2 (Stage 1 $\rightarrow$ 2)**: Working probe prototype & 4 C skill verification.
- **Gate 3 (Stage 2 $\rightarrow$ 3)**: HEITL Expert Jury evaluation & SMI score threshold.
- **Gate 4 (Stage 3 $\rightarrow$ 4)**: Legal setup, IP transfer, and commercial spin-off capital commitment.
