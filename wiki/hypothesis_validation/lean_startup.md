# 🔄 Eric Ries' Lean Startup Framework

The **Lean Startup Framework**, popularized by Eric Ries, focuses on eliminating waste and managing extreme uncertainty through rapid experimentation, short feedback cycles, and empirical validation.

---

## 🔁 The Build-Measure-Learn Feedback Loop

```
                     ┌──────────────────┐
                     │     IDEAS        │
                     └────────┬─────────┘
                              │ BUILD
                              ▼
┌──────────────────┐  ┌──────────────────┐
│     DATA         │  │    CODE / MVP    │
└────────┬─────────┘  └────────┬─────────┘
         │ MEASURE             │ LEARN
         └─────────────► ◄─────┘
```

1. **Build**: Create a Minimum Viable Product (MVP)—the smallest artifact required to begin validated learning.
2. **Measure**: Gather empirical data on how real users interact with the MVP.
3. **Learn**: Analyze metrics to determine whether to **Pivot** (change strategic direction) or **Persevere** (double down).

---

## 🧪 Key Concepts

### 1. Validated Learning
Testing fundamental business hypotheses using controlled experiments rather than vanity metrics:
- **Value Hypothesis**: Tests whether a product/service actually delivers value to customers once they use it.
- **Growth Hypothesis**: Tests how new customers will discover and adopt the product.

### 2. Minimum Viable Product (MVP)
An MVP is not a half-baked product; it is an experiment designed to test specific customer behavior with minimal engineering effort.

### 3. Pivot vs. Persevere
A structured review gate where teams evaluate empirical data to decide whether to alter product architecture, customer segment, or pricing model while preserving the core vision.
