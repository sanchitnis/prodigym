# 📊 Strategyzer Business Model & Value Proposition Canvas

Developed by Alexander Osterwalder and Yves Pigneur, the **Strategyzer Frameworks** provide visual templates for mapping, testing, and auditing the core strategic and commercial logic of a venture.

---

## 🏛️ 1. The Business Model Canvas (BMC)

Synthesizes a venture across 9 fundamental building blocks:

```
┌─────────────────┬─────────────────┬─────────────────┬─────────────────┬─────────────────┐
│ 8. Key Partners │ 6. Key Activities│ 1. Value        │ 4. Customer     │ 2. Customer     │
│                 │                 │    Propositions │    Relationships│    Segments     │
│                 ├─────────────────┤                 ├─────────────────┤                 │
│                 │ 7. Key Resources│                 │ 3. Channels     │                 │
├─────────────────┴─────────────────┼─────────────────┴─────────────────┴─────────────────┤
│ 9. Cost Structure                 │ 5. Revenue Streams                                  │
└───────────────────────────────────┴─────────────────────────────────────────────────────┘
```

---

## 🎯 2. The Value Proposition Canvas (VPC)

Zooms into the critical link between **Customer Profile** and **Value Map**:

```
        CUSTOMER PROFILE                              VALUE MAP
┌──────────────────────────────┐              ┌──────────────────────────────┐
│ • Customer Jobs              │              │ • Products & Services        │
│   (Functional, Emotional)    │   ALIGNMENT  │                              │
│ • Customer Pains             │ ◄──────────► │ • Pain Relievers             │
│ • Customer Gains             │              │ • Gain Creators              │
└──────────────────────────────┘              └──────────────────────────────┘
```

- **Fit Assessment**: Problem-Solution Fit is achieved when Pain Relievers directly eliminate top Customer Pains and Gain Creators produce target Customer Gains.

---

## 💡 Application in Project PRODIGY

In **PRODIGY Stage 3**, ventures use the BMC/VPC to demonstrate commercial viability and unit economics to the HEITL Expert Jury prior to Stage 4 hatching.
