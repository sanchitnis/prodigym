# ⚡ Jake Knapp's Design Sprint (GV / Google Ventures)

Developed by Jake Knapp at Google Ventures (GV), the **Design Sprint** is a compressed 5-day process to answer critical business questions through design, rapid prototyping, and user testing.

---

## 🗓️ The 5-Day Sprint Sequence

```
┌─────────────┬─────────────┬─────────────┬─────────────┬─────────────┐
│  DAY 1: MAP │ DAY 2: SKETCH│DAY 3: DECIDE│DAY 4: PROTO-│ DAY 5: TEST │
│             │             │             │      TYPE   │             │
│ Map problem │ Sketch      │ Pick best   │ Build       │ Test with   │
│ & choose    │ competing   │ solutions   │ realistic   │ 5 target    │
│ target.     │ solutions.  │ to test.    │ prototype.  │ users.      │
└─────────────┴─────────────┴─────────────┴─────────────┴─────────────┘
```

---

## 🔑 Core Principles

1. **Short-Circuiting the Slow Loop**: Instead of waiting to build and launch a full product before gathering feedback, a Design Sprint creates a realistic prototype to test with 5 target users in just five days.
2. **The Power of 5 Users**: User research shows that interviewing 5 target users uncovers ~85% of all usability and value-proposition issues.

---

## 💡 Application in Project PRODIGY

In **PRODIGY Stage 1 micro-sprints**, student teams run modified 5-day Design Sprints to prototype and test AI agent UI/UX concepts before writing backend production code.
