# 🔄 David Kolb's Experiential Learning Cycle in AI-Augmented R&D

Developed by educational theorist David Kolb, **Experiential Learning Theory (ELT)** posits that learning is the process whereby knowledge is created through the transformation of experience. It provides a 4-stage continuous learning cycle.

---

## 🔁 The 4-Stage Experiential Learning Cycle

```
                     ┌───────────────────────────┐
                     │  1. CONCRETE EXPERIENCE   │
                     │     (Doing / Micro-probe) │
                     └─────────────┬─────────────┘
                                   │
      ┌────────────────────────────┴────────────────────────────┐
      │                                                         │
┌─────┴─────────────────────┐             ┌─────────────────────┴────┐
│ 4. ACTIVE EXPERIMENTATION │             │ 2. REFLECTIVE            │
│    (Testing new ideas)    │             │    OBSERVATION           │
└─────┬─────────────────────┘             │    (Reviewing output)    │
      │                                   └─────────────────────┬────┘
      └────────────────────────────┬────────────────────────────┘
                                   │
                     ┌─────────────┴─────────────┐
                     │ 3. ABSTRACT               │
                     │    CONCEPTUALIZATION      │
                     │    (Formulating mental    │
                     │     models & prompt rule) │
                     └───────────────────────────┘
```

---

## 🛠️ The Four Stages Explained

1. **Concrete Experience**: Engaging directly in a real-world task or building a technical micro-probe.
2. **Reflective Observation**: Pausing to observe and review the outcome of the experience (e.g., evaluating code evals, model errors, user feedback).
3. **Abstract Conceptualization**: Synthesizing observations into generalized principles, mental models, or refined AI prompt strategies.
4. **Active Experimentation**: Applying the newly formed concepts to a new round of micro-probe experiments.

---

## 💡 Application in Project PRODIGY

In **AI-Augmented Co-Working**:
- **Concrete Experience**: Running an AI agent workflow or micro-challenge.
- **Reflective Observation**: Conducting peer reviews and auditing AI output errors.
- **Abstract Conceptualization**: Updating the **Obsidian Wiki** or **Gemini Prompt Playbook** with new prompt patterns.
- **Active Experimentation**: Deploying updated agent workflows in the next sprint.
