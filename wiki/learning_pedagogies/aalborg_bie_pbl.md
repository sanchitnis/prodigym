# 🏗️ Aalborg Model & Gold Standard Project-Based Learning (PBL)

Project-Based Learning (PBL) is a comprehensive instructional approach that engages learners in sustained, collaborative inquiry to solve complex, authentic problems. Two premier standards define global PBL excellence: **The Aalborg University PBL Model (UNESCO Chair)** and **The Buck Institute for Education (PBLWorks) Gold Standard PBL**.

---

## 🏛️ 1. The Aalborg University PBL Model

Recognized worldwide by UNESCO, Denmark's Aalborg University operates 50% of all curricula through problem-oriented, project-organized learning:

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│                              AALBORG PBL PRINCIPLES                                    │
├────────────────────────────────────────────────────────────────────────────────────────┤
│ • Problem-Oriented: Learning is initiated by exemplary real-world problems.            │
│ • Project-Organized: Learning is structured around project deliverables with deadlines. │
│ • Group-Based: 4–6 students manage self-governed project groups.                       │
│ • Interdisciplinary: Problems cross traditional departmental boundaries.               │
│ • Self-Governed: Students choose methodology and manage team dynamics.                 │
└────────────────────────────────────────────────────────────────────────────────────────┘
```

## 💡 Application in Project PRODIGY

PBL elements are embedded across **Srujana Stages 1–3**:
- **Sustained Inquiry**: 1–2 week micro-sprints built around technical R&D.
- **Public Product**: Every working probe must yield a public GitHub codebase and live demonstration.
- **Critique & Revision**: Iterative peer review and HEITL Jury evaluation rubrics.
