# 🎯 Ramesh Raskar's SPOT-PROBE Framework (MIT Media Lab / REDX)

The **SPOT-PROBE Framework**, developed by Professor Ramesh Raskar (MIT Media Lab / REDX), is a systematic methodology designed to prevent innovators from "aiming the cannon in the wrong direction." It separates problem space analysis from solution execution, ensuring teams do not jump into building before thoroughly understanding domain realities.

---

## 🔄 Core Operational Sequence

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│                               SPOT-PROBE INNOVATION CYCLE                              │
├────────────────────────────────────────────────────────────────────────────────────────┤
│ 1. SPOT ──> 2. PROBE ──> 3. GROW ──> 4. LAUNCH                                         │
│                                                                                        │
│ • SPOT: Identify grand challenges, construct problem canvases, map stakeholders.       │
│ • PROBE: Deconstruct root causes, run fast, low-cost technical/domain micro-sprints.   │
│ • GROW: Secure stakeholder adoption, run live pilot deployments.                      │
│ • LAUNCH: Incubate into enterprise contracts, corporate IP, or commercial spin-offs.  │
└────────────────────────────────────────────────────────────────────────────────────────┘
```

## 🛠️ Key Mechanisms & Tools

### 1. Brainswarming (Over Brainstorming)
Traditional brainstorming often yields superficial, unconstrained ideas. **Brainswarming** is a graph-based top-down and bottom-up problem-solving technique:
- **Top-Down**: Deconstruct the overarching goal into sub-problems and required resources.
- **Bottom-Up**: Identify available resources (AI models, compute, domain experts) and match them to sub-problems.

### 2. Time-Cost-Reach Plots
When evaluating micro-probe candidates, plot them on a 3-axis matrix:
- **Execution Time**: Can this probe yield empirical data in 1–2 weeks?
- **Resource Cost**: Can this probe run on minimal budget/compute?
- **Beneficiary Reach**: Does the solution directly impact target beneficiaries?

### 3. The Hexagon of Ideas (Multi-Disciplinary Fusion)
Evaluates proposals at the intersection of six vectors: *Technology, Design, Social Impact, Capital Sustainability, Regulatory Feasibility, and Human Agency*.

## 💡 Application in Project PRODIGY

In PRODIGY's **Srujana Stage 1**, student leads and mentors use SPOT-PROBE to map real-world friction in healthcare, agriculture, and education before writing code.
