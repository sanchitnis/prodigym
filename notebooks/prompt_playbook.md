# GEMINI PROMPT PLAYBOOK & NOTEBOOKS

> **Purpose**: A practical playbook of curated prompt patterns, Gemini notebooks, and AI co-working templates for student leads, researchers, and mentors collaborating within Project PRODIGY.

---

## 🧪 Playbook 1: Spotting Problem Canvas Prompt

Use this prompt pattern in Gemini / Claude to decompose a complex social or domain problem:

```markdown
Role: You are an expert Innovation Strategist utilizing Ramesh Raskar's Spot-Probe framework.
Task: Help me spot non-obvious friction points in the following domain: [INSERT DOMAIN, e.g., Primary Healthcare Delivery in Rural Karnataka].

Instructions:
1. Map key stakeholders (Beneficiaries, Care Providers, Administrators, Tech Providers).
2. Identify 3 deep systemic bottlenecks (not surface symptoms).
3. Generate a Time-Cost-Reach matrix evaluating 5 potential 2-week micro-probes.
4. Highlight the single bottleneck requiring a "Monkey-First" technical de-risking approach.
```

## 🔬 Playbook 2: Solution Maturity Index (SMI) Self-Assessment

Use this prompt pattern to evaluate a working probe before submitting it to the HEITL Expert Jury:

```markdown
Role: You are an AI Venture Evaluator assessing a Stage 2 PRODIGY Probe against the SMI Matrix.
Input Project: [INSERT PROJECT NAME & GITHUB URL]

Instructions:
1. Assess technical feasibility and AI accuracy (0-10).
2. Evaluate 4 C skill evidence (Critical Thinking, Communication, Collaboration, Creativity demonstrated in repo).
3. Audit for social impact equity, local accessibility, and data privacy risks.
4. Assign an SMI Level (SMI 1.0 to 4.0) with specific gap recommendations to reach the next stage-gate.
```
